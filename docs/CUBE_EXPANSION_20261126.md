# 原数据立方体增量（2026-11-26）

原 #data 页面新增 83 个流域；其中 80 个具有 FABDEM V1-2 原生 1 角秒 DEM，19 个具有 2000—2025 全部 26 年 MOD44B.061 三组分、Quality 与 Cloud 数值切片。原 103 个流域及其来源不变。每个新流域只启用已生成变量，不以其他流域或日期代替缺测。

从共享盘已下载校验的完整官方 ZIP / HDF 裁剪，在 D 盘中转。DEM 成员经 ZIP CRC 检验，保持原生半像元偏移网格；MOD44B 文件与下载记录的 SHA256 对照，在原生正弦网格读取窗口，保留 QA。百分比 SDS 的有效范围为 0—100，原水体代码 200、填充值 253 等非百分比代码在派生切片转为 nodata 255，原始 HDF 未修改。未按 QA 筛选，2024 年起产品处理连续性限制仍适用。

每个 GeoTIFF 回读数组与裁剪数组一致，记录 SHA256；PNG 是最长边 384 像素的显示派生图，不能当作原始数值。来源网格、掩膜及覆盖度核验记录位于私有归档。FABDEM 派生高程遵守 CC BY-NC-SA 4.0，官方 DOI：10.5523/bris.s5hqmjcdj8yo2ibzi9b4ew3sn；MOD44B DOI：10.5067/MODIS/MOD44B.061。

界面在原“已有切片”列表标注新增流域，提供当前流域 DEM / 年度植被快捷入口，缺少的变量禁用。新增流域原生边界接入同一地图选择器；不是单独的结果网页。

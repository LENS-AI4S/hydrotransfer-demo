# 已完成光学案例的网页预览

2026-11-10 首批接入100项已完成且已交付光学成果的候选关系，覆盖98个原生Level 8流域、80条来源事件。为方便对照，光学检出与未检出各50项；这是浏览批次，不用于估计全球检出率或洪水发生率。GBFEID、HYBAS_ID、原日期、原处理状态均保持原值。

结果页先展示总表，再按GBFEID展开来源与时间、水文、Groundsource、SAR和MODIS。水文和Groundsource100项均已完成；SAR只接入16项具有完成回执且CSV校验通过的成果，原空值和其原因保留，其他84项标记尚未交付。本批不计算综合可信等级或独立洪水次数。旧11项报告保留在“历史试点报告”。

切片从NAS既有成果生成，另存独立的web_previews目录。光学来源ZIP按交付回执SHA-256核验；水文来源总表按完成manifest核验；Groundsource检查原事件JSON的GBFEID、边界哈希与匹配数；各模态检查同一候选的身份、流域和原始日期。原始数据和正在运行的计算不修改。

公开文件仅包含浏览图、候选索引、必要记录与逐日数值。首批12项光学案例包含467帧逐日候选水体掩膜；像元权重汇总与原daily_series.csv面积逐日一致。蓝色为候选水体，灰色为该日无观测，不能称为已确认淹没范围。原始TIFF、SQLite、ZIP、内网地址及完整NAS路径不进入网页资源。

页面25项一页，详情图件和逐日帧按需读取，首屏只读取索引和当前页，图件在点击案例后读取。分片格式可按相同方式扩大。NAS原始浏览图合计约44.7MB；为避免GitHub逐文件同步超时，发布时按案例内嵌图件，打包为104个资源、约59.4MB。图片字节经过base64往返核验，未重新计算栅格。访客不需要连接内网NAS。

导出入口：scripts/export_global_evidence.py；随后运行scripts/pack_global_evidence.py生成按案例打包的发布资源。必须显式提供本地科学项目与NAS成果根目录，默认100项，上限200项。导出是只读适配，不启动GEE或其他科学任务。每次生成独立NAS预览目录，可通过--preview-dir重用具有本工具标记的目录。源文件审计仅保留在NAS预览目录及本地忽略的qa目录。

验证：node scripts/check-global-results.cjs；覆盖100项唯一ID、各来源状态、NAS预览SHA、分页/筛选/搜索、动态日期帧及历史入口。工程核验不等同于科学识别精度验证。

本批输入已同步扩展：98个流域提供全部8变量，新增2,744张静态/五期土地覆盖预览、各2,914张土壤水分与流量日切片，以及原生边界和真实河段。输入时序限于相同案例观测窗口。案例详情可直接打开同一GBFEID的输入预览，流程页与数据来源登记同步反映真实接入状态。详见DATA_CUBE.md。

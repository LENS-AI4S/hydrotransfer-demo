# HydroTransfer

全球流域参数移植与洪水模拟研究展示网页。

**在线界面：[打开数据立方体](https://lens-ai4s.github.io/hydrotransfer-demo/#data)**

- 全球 HydroBASINS Level 8：190,675 个分区，支持上下游高亮。
- 新增100项光学已完成案例，按GBFEID关联水文、Groundsource与已交付的SAR证据；12项共467帧逐日光学切片。
- 历史五流域报告与11项案例另行保留，保持原判定口径。
- 数据立方体：8变量、7个土壤深度、五期土地覆盖；原五试点保留完整时序，新增98个案例流域含2,744张静态预览、各2,914张土壤水分与流量日切片，支持地图、日期切换及结果联动。
- 来源候选不是已确认的独立洪水次数，证据采用待核定。参数移植模拟仍为演示。

## 数据立方体

网页使用预生成的PNG，不要求访客连接内网NAS。原始COG/Zarr和完整立方体数组没有放入本仓库；网页没有修改NAS数据的操作。浏览内容和预览图片可以被保存。

土壤与DEM为静态资料；土地覆盖可选择2000、2005、2010、2015、2020年。土壤水分覆盖2000-01-01至2025-12-31，共9,497天，26个年度资源按需加载。GloFAS v5.0流量保留0.05°原生格点与实际时间戳2000-01-02至2026-01-01，共9,497天，按27个日历年资源加载；2026年只有1月1日。流量仅展示已有切片，不计算流域均值、流量总和或出口流量。各时间轴独立，不插值中间年份或缺测日。五个试点已有完整在线日切片；新增98个流域提供本批100项光学案例观测窗口内的每日输入，其他分区需按需提取。层叠视图用于浏览土壤深度，不是三维地质模型。详见 [数据立方体说明](docs/DATA_CUBE.md)。

## 代码与部署

`global-results.js`：光学完成案例与分来源结果；`cube-viewer.js`：立方体界面；`research-results.js`：多模态成果；`app-hydrobasins.js`：地图、选择与导航；`hydro-topology.js`：上下游关系。`services/` 是可选的只读预览服务代码，当前没有远程部署。

项目只维护本地版与 GitHub Pages 线上版。本地完成修改和验证后，同步到本仓库；GitHub Pages 从 `main` 分支根目录自动构建与部署，以部署成功和线上资源核对通过作为发布完成条件。无需运行NAS服务即可查看当前网页。本仓库是展示工程，科学处理工程另行维护。

本地可用 `python -m http.server 8000` 打开预览。

## 来源

HydroBASINS v1c、Natural Earth、HWSD v2.2、GLC_FCS30D 2000/2005/2010/2015/2020（NatCap / University of Minnesota年度COG派生版）、GEBCO 2026、ScienceDB V3 ERA5-Land / SMAP L4融合土壤水分、GloFAS v5.0（avg_dis）。数据版本、限制、单位及界面参考见 [说明文档](docs/DATA_CUBE.md)。来源数据遵循各提供方许可；预览不替代正式计算用的原始数据。

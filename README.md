# HydroTransfer

全球流域参数移植与洪水模拟研究展示网页。

**在线界面：[打开数据立方体](https://lens-ai4s.github.io/hydrotransfer-demo/#data)**

- 全球 HydroBASINS Level 8：190,675 个分区，支持上下游高亮。
- 五个试点的真实研究成果：11条来源候选、535条证据、145条关联，6项MODIS共232个逐日帧。
- 数据立方体：全球分区选择、7变量、7个土壤深度、140张静态/五期土地覆盖预览，以及47,485张逐日土壤水分预览；支持年份、日期切换与播放。
- 来源候选不是已确认的独立洪水次数，证据采用待核定。参数移植模拟仍为演示。

## 数据立方体

网页使用预生成的PNG，不要求访客连接内网NAS。原始COG/Zarr和完整立方体数组没有放入本仓库；网页没有修改NAS数据的操作。浏览内容和预览图片可以被保存。

土壤与DEM为静态资料；土地覆盖可选择2000、2005、2010、2015、2020年。土壤水分覆盖2000-01-01至2025-12-31，共9,497天，26个年度资源按需加载。两个时间轴独立，不插值中间年份或缺测日。五个试点已有完整在线日切片，其他分区需按需提取。层叠视图用于浏览土壤深度，不是三维地质模型。详见 [数据立方体说明](docs/DATA_CUBE.md)。

## 代码与部署

`cube-viewer.js`：立方体界面；`research-results.js`：多模态成果；`app-hydrobasins.js`：地图、选择与导航；`hydro-topology.js`：上下游关系。`services/` 是可选的只读预览服务代码，当前没有远程部署。

项目只维护本地版与 GitHub Pages 线上版。本地完成修改和验证后，同步到本仓库；GitHub Pages 从 `main` 分支根目录自动构建与部署，以部署成功和线上资源核对通过作为发布完成条件。无需运行NAS服务即可查看当前网页。本仓库是展示工程，科学处理工程另行维护。

本地可用 `python -m http.server 8000` 打开预览。

## 来源

HydroBASINS v1c、Natural Earth、HWSD v2.2、GLC_FCS30D 2000/2005/2010/2015/2020（NatCap / University of Minnesota年度COG派生版）、GEBCO 2026、ScienceDB V3 ERA5-Land / SMAP L4融合土壤水分。数据版本、限制、单位及界面参考见 [说明文档](docs/DATA_CUBE.md)。来源数据遵循各提供方许可；预览不替代正式计算用的原始数据。
